# Changelog

## 작성 규칙

- 사용자가 체감하는 변경을 한 줄로 작성합니다.
- 새로운 기능은 `추가된 기능`, 기존 기능 개선과 버그 수정은 `개선 및 수정`, 제거된 기능은 `종료된 기능`에 기록합니다.
- 변경 사항은 해당 PR에서 Unreleased에 추가합니다.
- 릴리스 준비 시 Unreleased의 내용을 버전과 날짜가 있는 항목으로 확정하고, 맨 위에 새로운 Unreleased를 만듭니다.
  - 예시: [1.0.0] - 2030-01-01
- 최신 버전이 위에 오도록 작성합니다.

### 추가된 기능

- 댓글 알림을 말풍선 아이콘으로 구분하고, 누르면 이전 댓글을 유지한 채 해당 댓글 위치로 이동합니다.
- 공지·과제·제출물 상세에서 댓글을 조회·작성·수정·삭제하고, 전체 개수 확인과 10개씩 더 보기를 사용할 수 있습니다.
- 스터디 일정 탭에서 오늘과 날짜별 일정을 확인하고 공지·과제 상세 화면으로 이동할 수 있습니다.
- 스터디 프로필 이미지가 추가되었습니다.
  - 스터디 프로필을 추가할 수 있고 수정할 수 있습니다.
  - 스터디 프로필 이미지는 5MB 제한과 JPEG, JPG, PNG, WEBP 확장자만 허용합니다.
  - 스터디 프로필 이미지가 표시됩니다.
    - 스터디 목록, 스터디 카드
    - 스터디 관리, 스터디 정보
    - 선택된 스터디 이미지가 이미 있는 스터디 수정 페이지
- 리마인드 기능이 추가되었습니다.

- 스터디 참여 확인 페이지가 추가되었습니다.
  - 초대 링크로 스터디 참여시 스터디 참여 확인 페이지에서 참여할 페이지의 정보를 알 수 있습니다.

### 개선 및 수정

- 스터디 생성, 스터디 참여, 공지 생성, 과제 생성같이 목록 길이에 의해 접근하기 어려운 핵심동작을 Floating UI로 제공하여 사용자가 특정 목록의 길이에 의존하지 않는 접근이 가능하도록 개선합니다.

- IOS PWA 환경에서 하단 탭바의 높이를 인디케이터 영역에 닿지 않도록 높였습니다.

## [2.1.1]

### 개선 및 수정

- 과제 제출물에서 이미지 파일인 경우 해당 이미지 파일을 첨부 파일 목록에서 렌더링합니다.
- 생성/수정 과정에서 이미지 등록시 해당 이미지가 렌더링되도록 합니다.
  - 공지
  - 과제
  - 과제 제출물
- 공지/과제/과제 제출물의 첨부 이미지를 눌러 크게 보고, 여러 이미지 사이를 이동할 수 있습니다.
- 생성/수정 과정에서 등록한 이미지 미리보기도 눌러 크게 볼 수 있습니다.
- 공지와 동일하게 과제 내용 입력시에 컨텐츠 양에따라 입력 크기가 조절됩니다.
- 알림 목록에 존재하는 알림을 클릭하고 이동한 페이지에서 이전 페이지로 이동하는 버튼을 클릭하면 알림 목록으로 이동합니다.

## [2.1.0]

### 추가된 기능

**이제 공지/과제/과제 제출물에 이미지/파일을 첨부할 수 있습니다.**

- 공지 생성/수정시 이미지 첨부 기능 추가
- 과제 생성/수정시 이미지 첨부 기능 추가
- 과제 제출물 생성/수정시 파일 첨부 기능 추가

이미지는 JPEG, JPG, PNG, WEBP 확장자만 허용합니다.
각 공지/과제/제출물당 10개 첨부할 수 있으며 한 파일당 5MB 제한이 존재합니다.

**공지/과제/과제 제출물에 첨부한 이미지를 확인할 수 있습니다.**

- 공지/과제 확인시 첨부된 이미지 목록이 렌더링 됩니다.
- 과제 제출물 확인시 첨부된 파일 목록이 렌더링 됩니다.

- 과제 제출물에서 첨부된 파일 목록에 존재하는 파일을 다운로드할 수 있습니다.

# Changelog

## 작성 규칙

- 사용자가 체감하는 변경을 한 줄로 작성합니다.
- 새로운 기능은 `추가된 기능`, 기존 기능 개선과 버그 수정은 `개선 및 수정`, 제거된 기능은 `종료된 기능`에 기록합니다.
- 변경 사항은 해당 PR에서 Unreleased에 추가합니다.
- 릴리스 준비 시 Unreleased의 내용을 버전과 날짜가 있는 항목으로 확정하고, 맨 위에 새로운 Unreleased를 만듭니다.
  - 예시: [1.0.0] - 2030-01-01
- 최신 버전이 위에 오도록 작성합니다.

## [Unreleased]

### 추가된 기능

**이제 공지/과제/과제 제출물에 이미지/파일을 첨부할 수 있습니다.**

- 공지 생성/수정시 이미지 첨부 기능 추가
- 과제 생성/수정시 이미지 첨부 기능 추가
- 과제 제출물 생성/수정시 파일 첨부 기능 추가

이미지는 JPEG, JPG, PNG, WEBP 확장자만 허용합니다.
각 공지/과제/제출물당 10개 첨부할 수 있으며 한 파일당 5MB 제한이 존재합니다.

**공지/과제/과제 제출물에 첨부한 이미지를 확인할 수 있습니다.**

- 공지/과제 확인시 첨부된 이미지 목록이 렌더링 됩니다.
- 과제 제출물 확인시 첨부된 파일 목록이 렌더링 됩니다.

- 과제 제출물에서 첨부된 파일 목록에 존재하는 파일을 다운로드할 수 있습니다.

### 개선 및 수정

- 알림 목록에 존재하는 알림을 클릭하고 이동한 페이지에서 이전 페이지로 이동하는 버튼을 클릭하면 알림 목록으로 이동하도록 수정되었습니다.

### 종료된 기능

## [2.0.6]

2.0.6에 체인지 로그 정책이 도입되었습니다.
현재 변경사항은 2.0.6 변경사항을 전부 담고 있지 않은 형태며 체인지 로그 정책이 추가된 시점 이후의 내역들만 반영되어 있습니다.
이후 버전부터는 모든 변경사항들에 대한 내역이 기록됩니다.

### 추가된 기능

- 과제의 내 제출과 제출 현황에서 마감 후 제출한 과제를 구분할 수 있도록 `지각 제출` 배지를 추가했습니다.

### 개선 및 수정

- 카카오 로그인 후 현재 접속한 사이트로 돌아오도록 개선했습니다.
- 설치형 웹 앱(PWA)의 아이콘과 설정 변경 사항이 반영되도록 캐시 정책을 개선했습니다.

# Changelog

## 작성 규칙

- 사용자가 체감하는 변경을 한 줄로 작성합니다.
- 새로운 기능은 `추가된 기능`, 기존 기능 개선과 버그 수정은 `개선 및 수정`, 제거된 기능은 `종료된 기능`에 기록합니다.
- 변경 사항은 해당 PR에서 Unreleased에 추가합니다.
- 릴리스 준비 시 Unreleased의 내용을 버전과 날짜가 있는 항목으로 확정하고, 맨 위에 새로운 Unreleased를 만듭니다.
  - 예시: [1.0.0] - 2030-01-01
- 최신 버전이 위에 오도록 작성합니다.

### 추가된 기능

**이제 공지/과제/과제 제출물에 이미지/파일을 첨부할 수 있습니다.**

- 공지 생성/수정시 이미지 첨부 기능 추가
- 과제 생성/수정시 이미지 첨부 기능 추가
- 과제 제출물 생성/수정시 파일 첨부 기능 추가

이미지는 JPEG, JPG, PNG, WEBP 확장자만 허용합니다.
각 공지/과제/제출물당 10개 첨부할 수 있으며 한 파일당 5MB 제한이 존재합니다.

**공지/과제/과제 제출물에 첨부한 이미지를 확인할 수 있습니다.**

- 공지/과제 확인시 첨부된 이미지 목록이 렌더링 됩니다.
- 과제 제출물 확인시 첨부된 파일 목록이 렌더링 됩니다.
  - 이미지는 확인할 수 있지만 아직 파일은 다운로드 하여 실제 내용물을 확인 할 수 없습니다.

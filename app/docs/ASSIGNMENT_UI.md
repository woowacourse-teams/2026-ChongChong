## 구현 범위

- 역할별 목록, 빈 목록, 제출 완료/미제출/대상 외 배지, 마감·리마인드 표시.
- 요약·상세 전환, 제출 집계, 내 제출, 대상자별 상태, 로컬 알리기.
- 리더 작성·수정·삭제 및 확인 모달, 필수 입력, 마감/리마인드 날짜·시간, 공개 여부, 리더 제출 참여.
- 이미지 첨부 UI는 기존 Expo ImagePicker를 재사용한다.
- 제출·수정, 링크 형식 검증, Expo DocumentPicker로 로컬 파일 선택·제거, 이탈 확인.
- 공개 과제는 다른 제출물 조회, 비공개 과제의 스터디원은 자기 제출만 표시한다. 리더는 전체 상태를 본다.
- 스터디 목록·홈의 과제 수와 제출 상태를 같은 공급자의 상태로 연결한다.

시연 시계는 기존 `previewClock.ts`의 2026-08-05 17:59로 고정돼 있다. 과거 날짜·시간 선택 제한은 이 시계를 기준으로 한다. 기존 v1 정책에 맞춰 마감 후에도 제출·수정 진입을 허용한다. 새로고침하면 목 상태가 초기화된다. 파일은 로컬 URI만 보유하며 실제 업로드·알림 전송은 없다. 링크는 조회/복사 가능한 텍스트이고 외부 이동은 연결하지 않았다.

## 증거와 판정 한계

검증용 이미지는 사용자 요청으로 제거했다. 당시 실행 결과는 이 문서의 검증 항목과 텍스트 검토 보고서에 남긴다. 이미지 재대조에는 새 캡처가 필요하다.

확인한 화면·속성·상태 범위에서 차단할 불일치는 남지 않았다. Figma 축소 캔버스와 실제 뷰포트 크기가 달라 유효한 동일 크기 픽셀 diff/일치율은 산정하지 않았다. 모든 레이어를 개별 실측한 결과로 주장하지 않는다. JPEG 캡처의 알파 채널은 검증하지 않았다.

네이티브는 번들 생성까지만 확인했다. iOS/Android 실기기·시뮬레이터 실행, OS 파일/사진 권한 동작, 키보드·Safe Area, 스크린리더는 미검증이다. 첨부 이미지를 포함한 저장 후 전체 렌더링과 모든 리마인드 경계 조합은 별도 회귀 검증이 필요하다. 서버 권한·저장·업로드·푸시·실시간 시계 연동은 후속 범위다.

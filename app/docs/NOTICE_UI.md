## 범위와 상태

목록, 리더 요약·상세·대상자별 확인/알림 상태, 작성·수정·삭제 확인, 로컬 이미지 선택/제거, 리마인드 날짜/시간 선택, 스터디원 읽는 중·읽음 완료·미대상을 구현했다. 새 공지와 수정·삭제 결과는 목록·홈·내 스터디 공지 건수에 반영된다. 삭제된 공지의 목 알림도 제거한다.

리더에게만 작성·수정·삭제와 알리기 동작을 노출하고 provider에서도 제한한다. 스터디원은 자신이 수신 대상이고 아직 읽지 않은 공지의 세로 스크롤 끝에 도달했을 때 읽음 처리된다. 알림 클릭의 읽음과 공지 본문의 읽음은 별도 상태다. 미대상은 상세를 볼 수 있지만 읽음 진행률·완료 표시 및 상태 변경이 없다. 가로 이미지 목록의 마지막 이미지까지 넘기는 것은 읽음 조건에 포함하지 않는다.

변경된 제목·본문·이미지·리마인드가 있으면 화면 이탈 시 확인한다. 저장 후 기존 상세로 돌아갈 때 `dismissTo`로 중복 상세를 남기지 않는다. 미작성 필수 입력은 저장 버튼을 비활성화한다. 서버 인증·API·실제 파일 업로드·푸시 발송은 포함하지 않는다.

## 비교 한계 및 시연 가정

- 스터디명·역할명은 기존 앱의 선택한 스터디 데이터를 유지한다. 본문은 Figma의 예시 문구를 바탕으로 긴 글 시나리오를 구성했다. 진행률은 실제 스크롤 비율이므로 시안의 고정38%를 복사하지 않는다.
- 미대상 fixture에는 복수 이미지 상태 검증을 위해 이미지2개를 포함한다. 그 결과 미대상 목록 카드에도 실제 첨부 썸네일이 보인다. Figma 목록의 해당 예시 카드에는 이미지가 없다. 이는 동일 데이터·동일 상태의 픽셀 비교 대상이 아니다.
- 미리보기 시계는2026-08-05 17:59로 고정하고 예약까지의 분/시간/일을 계산한다. 실제 시간 경과에 따른 예약 실행은 없다. 읽음 완료 시각도 시안 예시8월3일21:14를 사용한다.
- 시간 선택창과 목록은 `previewClock.ts`의 같은 기준 시각을 사용한다. 현재와 같거나 지난 예약은 선택·완료할 수 없다. 미래 날짜에서 과거 시간이 되는 날짜로 변경하면 시연에서 유효한18:00으로 선택을 보정한다.
- 상태와 선택 이미지 URI는 메모리에만 저장하며 새로고침·시나리오 재선택 시 초기화한다. OS 이미지 권한 및 업로드 실패 정책은 API/네이티브 연동 단계에서 검증해야 한다.
- 도구의 실제 웹 캡처가 JPEG이고 Figma 내보내기는 PNG다. 캡처 색 변환과 글자 안티앨리어싱이 달라 전체 픽셀100% 일치를 판정하지 않는다. 검사 패널의 폰트·치수·색과 실제 요소 및 화면 배치를 함께 대조했다.
- iOS/Android 실기기, 시스템 뒤로가기·스와이프 이탈, 실제 Safe Area·키보드·글자 확대·OS 파일 선택기는 미검증이다.

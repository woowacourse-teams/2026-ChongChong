## 구현 동작

- 멤버 목록: 자신의 이름, 리더 왕관, 리더의 다른 멤버 관리 메뉴.
- 양도: 대상에게 왕관 이동, 현재 사용자는 스터디원으로 변경되고 관리 권한 소멸.
- 방출: 해당 멤버 제거, 스터디 목록 인원 수 동기화.
- 프로필: 선택한 스터디에만 이름 저장, 홈 이름과 멤버 목록에 반영. 전역 이름과 다른 스터디는 유지.
- 정보 수정: 리더만 접근·저장. 이름 15자, 설명 30자 제한.
- 프로필 이름: 공백만 입력 불가, 8자 제한. 길이 초과 시 오류와 저장 비활성화.
- 삭제·탈퇴: 확인 후 해당 스터디 제거, 목록으로 복귀.
- 수정 도중 뒤로가기: 저장하지 않은 변경 확인.
- 양도 전 역할을 fixtureRole로 보존해 역할 전환으로 기존 공지·과제 목 데이터가 교체되지 않도록 한다. 권한은 현재 role을 따른다.

## 의도적 차이와 제한

- 정보 수정 CTA는 시안의 “스터디 만들기” 대신 동작에 맞는 “스터디 수정하기”로 표시한다.
- 초대 링크는 `chongchong.example`의 시연용 문자열이다. 실제 초대 발급·서버 참여는 구현하지 않았다.
- 탈퇴 및 편집 이탈 확인은 기존 공통 모달을 재사용한다.
- 방출자의 향후 재참여 차단, 과거 공지·과제 대상 정책은 서버 연동 범위에서 확정해야 한다.
- iOS·Android 실제 실행, 시스템 뒤로가기·키보드, 네이티브 클립보드, VoiceOver/TalkBack은 미검증이다.
- 웹에서 확인한 결과를 네이티브 일치로 간주하지 않는다.

## 멤버 하단 탭 유지

사용자 요청에 따라 멤버 화면에서도 공통 하단 탭을 유지한다. 멤버 탭만 숨기던 설정을 제거해 홈·공지·과제로 바로 이동할 수 있게 했다. 이는 하단 탭이 없는 Figma 멤버 프레임과의 의도된 차이다.

## 멤버 공통 헤더

사용자 요청에 따라 멤버 화면의 단독 “멤버” 헤더를 공통 StudyHeader로 변경했다. 스터디 이름·현재 스터디 프로필 이름·역할·햄버거를 표시하고, 햄버거는 스터디 관리로 이동한다. 하단 탭도 유지한다. Figma의 단독 멤버 헤더와는 의도된 차이다.

## 스터디 제목 크기 조정

사용자 요청으로 공통 스터디 헤더 제목을 18/28에서 16/24(large 토큰)로 줄였다. 홈·공지·과제·멤버에 동일하게 적용한다. 이후 Figma 데스크톱에서 헤더 1702:19617, 1702:19584, 1702:19508, 1702:19928도 16/24로 변경하고 스타일 적용을 확인했다. 카드 제목은 기존 크기를 유지한다.

기존 evidence/327의 멤버 캡처는 공통 헤더·하단 탭 반영 전 중간 검증 자료다. 최종 헤더와 하단 탭은 이후 웹에서 별도로 확인했으며 이 캡처로 최종 전체 화면 일치를 주장하지 않는다.

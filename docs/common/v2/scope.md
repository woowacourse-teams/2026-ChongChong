## 근거

기준일은 2026-10-08이며 기준 커밋은 `263bdafe8f05d6abd9376476951ba24d46adc121`이다.
`frontend/src/features`의 화면·요청 코드와 `backend/src/main/java/withoutc/chongchong`의 서비스·정책·모델을 대조했다.
각 기능 문서의 근거 링크는 실제 구현 파일을 가리킨다.

## 사용할 수 있는 기능

| 범위 | 기능 |
| --- | --- |
| 웹·서버 연결 | 카카오 로그인, 스터디 생성·참여·수정·삭제, 멤버 목록·방출·탈퇴 |
| 웹·서버 연결 | 공지 자동 읽음, 과제 제출·수정·공개 설정·리더 참여·5개 상태 표시 |
| 웹·서버 연결 | 계정 이름 수정, 소속 스터디 이름 동기화, 계정 탈퇴, 알림함, Web Push 구독 |
| 서버만 제공 | 공지·과제의 예약 리마인드 등록·변경·발송 |
| 현재 구현 없음 | Google·Apple 로그인, 리더 양도, 스터디별 독립 이름 수정, 이미지·파일 첨부 |

모바일 홈 화면에 설치해 사용하는 기능과 브라우저 푸시는 웹에서 제공한다. 삭제한 네이티브 시연용 패키지는 이 문서의 기능 범위에 포함하지 않는다.

어떤 행동을 할 수 있는지는 역할뿐 아니라 스터디에 소속되어 있는지, 확인·제출 대상인지, 제출물이 공개되어 있는지에 따라 달라진다.
서버에서도 이 조건을 확인하므로, 화면에 버튼을 숨기는 것만으로 권한을 제한하지 않는다.

## 동작을 확인할 때 사용할 시나리오

아래 표는 기능을 확인할 때 기대하는 결과다. 이번 문서 작업에서 실제로 실행한 테스트 결과는 아니다.

| 조건과 행동 | 기대 결과 |
| --- | --- |
| 로그인 후 스터디 생성 | 생성자가 리더가 되고 내 목록에 표시 |
| 발급 후 3일이 지난 초대 링크로 참여 | 참여 거부 |
| 이미 50개 스터디에 소속되거나 대상 스터디가 50명인 상태에서 참여 | 제한 오류 |
| 공지·과제 작성 뒤 새 멤버 가입 | 이전 글 열람 가능, 확인·제출 대상에는 추가되지 않음 |
| 확인 대상 멤버가 공지 끝까지 읽기 | 자동 읽음 요청과 완료 상태 표시 |
| 과제 마감 뒤 처음 제출 | 지각 제출, 리더 완료 인원에 포함 |
| 비공개 과제에서 타인 제출물 조회 | 일반 멤버 접근 거부 |
| 계정 이름 수정 | 모든 소속 스터디의 멤버 이름에 반영 |
| 리더가 스터디 탈퇴 또는 회원탈퇴 | 서버에서 거부 |
| 알림함 항목 선택 | 읽음 처리 요청 및 관련 화면 이동 |

## 확인한 내용과 아직 확인하지 않은 내용

이번 작업에서는 문서를 정리하고 독립 시연 패키지를 제거했다. 문서의 코드 근거와 내부 링크, 삭제한 파일의 범위를 확인했다.
실제 로그인과 HTTP 요청을 통한 전체 흐름, 운영 데이터 정리, 푸시 수신, 배포 상태는 확인하지 않았다.
과거 문서에 적힌 테스트 통과 횟수도 이번 작업의 검증 결과에는 포함하지 않았다.

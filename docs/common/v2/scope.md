# 문서 기준과 구현 범위

[← 현재 PRD](README.md) · [구현 범위](scope.md)

## 근거

2026-11-05 통합 개발 브랜치의 `f21a30c1`을 기준으로 백엔드 구현·테스트·API 계약을 대조했다.
웹 연동 여부는 해당 화면·요청·응답 검증 코드를 확인한 범위로 구분한다. 코드에 구현된 기능과 실제 배포·외부 서비스 검증 결과는 다르다.
`frontend/src/features`의 화면·요청 코드와 `backend/src/main/java/withoutc/chongchong`의 서비스·정책·모델을 대조했다.
각 기능 문서의 근거 링크는 실제 구현 파일을 가리킨다.

## 사용할 수 있는 기능

| 범위 | 기능 |
| --- | --- |
| 웹·서버 연결 | 카카오 로그인과 다중 세션, 스터디 생성·참여·수정·삭제, 멤버 목록·방출·탈퇴 |
| 웹·서버 연결 | 공지 자동 읽음, 과제 제출·수정·공개 설정·리더 참여·5개 상태 표시 |
| 웹·서버 연결 | 계정 이름 수정, 소속 스터디 이름 동기화, 계정 탈퇴, 알림함, Web Push 구독·최초 클릭 기록 |
| 웹·서버 연결 | 공지·과제 예약 입력·변경, 파일 업로드·완료·첨부 표시, 과제·제출물 다운로드, 스터디 대표 이미지 설정·초기화 |
| 서버 API | 공개 스터디 탐색·이름 검색·참여 전 정보, 공개 여부 설정·ID 기반 참여 |
| 서버 API·웹 미연동 | 홈 프로필 이미지 변경·초기화, 과제 제출 대상 개별·전체 지정·변경 및 기존 제출물 보존, 월간 캘린더 |
| 서버 API | 공지·과제·제출물 댓글 조회·작성·수정·삭제와 댓글 알림 |
| 현재 구현 없음 | Google·Apple 로그인, 리더 양도, 스터디별 독립 이름·사용자 이미지 수정 |

웹과 서버의 입력·응답 제약도 일부 다르다. 과제의 제출 방법은 서버에서 선택 값이지만 웹 폼에서는 필수다.
제출 내용은 웹도 링크·첨부로 대체할 수 있으며 제출물 상세의 `createdAt·content=null`도 허용한다. 과제 대상 선택과 내 제출 조회의 `assigned`에 따른 수정 제한은 웹에 아직 반영되지 않았다.

모바일 홈 화면에 설치해 사용하는 기능과 브라우저 푸시는 웹에서 제공한다. 삭제한 네이티브 시연용 패키지는 이 문서의 기능 범위에 포함하지 않는다.

어떤 행동을 할 수 있는지는 역할뿐 아니라 스터디에 소속되어 있는지, 확인·제출 대상인지, 제출물이 공개되어 있는지에 따라 달라진다.
서버에서도 이 조건을 확인하므로, 화면에 버튼을 숨기는 것만으로 권한을 제한하지 않는다.

## 동작을 확인할 때 사용할 시나리오

아래 표는 기능을 확인할 때 기대하는 결과다. 이번 문서 작업에서 실제로 실행한 테스트 결과는 아니다.

| 조건과 행동 | 기대 결과 |
| --- | --- |
| 로그인 후 스터디 생성 | 생성자가 리더가 되고 내 목록에 표시 |
| 서로 다른 브라우저에서 로그인 후 한쪽 갱신·로그아웃 | 다른 브라우저의 세션 유지 |
| 발급 후 3일이 지난 초대 링크로 참여 | 참여 거부 |
| 이미 50개 스터디에 소속되거나 대상 스터디가 50명인 상태에서 참여 | 제한 오류 |
| 공지·과제 작성 뒤 새 멤버 가입 | 이전 글 열람 가능, 확인·제출 대상에는 자동 추가되지 않음. 과제는 리더가 나중에 추가 가능 |
| 확인 대상 멤버가 공지 끝까지 읽기 | 자동 읽음 요청과 완료 상태 표시 |
| 과제 마감 뒤 처음 제출 | 지각 제출, 리더 완료 인원에 포함 |
| 과제 제출 후 대상에서 제외하고 재추가 | 기존 제출물 보존, 제외 중 제출·수정 거부, 재추가 후 동일 제출물 수정 가능 |
| 빈 대상 목록 전송 / 마감 후 대상 변경 | 빈 목록은 거부하고 마감 후 변경은 허용 |
| 예약 목록 생략·null / 빈 배열로 수정 | 기존 예약 유지 / 대기 예약 제거 |
| 홈 프로필 초기화 후 스터디 멤버 조회 | 기본 이미지 반영, 스터디 대표 이미지는 유지 |
| 월간 캘린더 조회 | 모든 공지와 본인 현재 지정 과제의 생성·마감 반환 |
| 비공개 과제에서 타인 제출물 조회 | 일반 멤버 접근 거부 |
| 계정 이름 수정 | 모든 소속 스터디의 멤버 이름에 반영 |
| 리더가 스터디 탈퇴 또는 회원탈퇴 | 서버에서 거부 |
| 알림함 항목 선택 | 읽음 처리 요청 및 관련 화면 이동 |
| 브라우저 푸시 클릭 | 서명 토큰으로 최초 클릭 기록 요청과 관련 화면 열기를 각각 시도 |
| 인증 후 파일 업로드 URL 발급 | 파일 ID·PUT URL·만료 시각 반환. 실제 업로드 완료나 게시물 첨부는 보장하지 않음 |
| 과제·제출물 상세 조회 후 첨부 다운로드 | 조회 권한이 있으면 downloadUrl 반환. 해당 URL로 S3에서 원본 파일명으로 다운로드 |

## 확인한 내용과 아직 확인하지 않은 내용

이번 갱신은 `f21a30c1`의 구현·계약을 기준으로 문서를 정비하고 공지·과제 리마인드의 부분 수정 회귀 테스트를 보완한다.
실행 명령과 결과, 남은 연동 항목은 [#643 정비 기록](../../verification/643-backend-test-spec-alignment.md)에 남긴다.
실제 카카오 로그인, 운영 푸시 수신, 브라우저·S3 업로드/다운로드와 배포 상태는 별도 확인이 필요하다.

# 문서 기준과 확인할 정책

[← v2 개요](README.md) · [v1 대비 변경](changes.md)

## 기준

- 디자인: Figma `Design ver2` 페이지의 ‘디자인 v2’ 섹션과 인접 기능 메모.
- 확인일: 2026-09-14. 화면 이름과 노드 링크를 각 기능 문서에 기록했다.
- 비교 대상: [v1 PRD](../v1/README.md)의 기준 소스와 문서 커밋 `fc8d19de69d7ee6d188ba2428062c9cc90738e66`.
- 이 문서는 디자인 요구사항이다. v2 기능이 구현·배포되었다는 의미가 아니다.
- Figma 커넥터는 연결 계정 권한 오류로 읽지 못했고, 브라우저에서 실제 프레임과 안내 문구를 확인했다.

## 해석 기준

- 화면에 있는 입력·상태·메뉴와 메모의 의도를 근거로 기록한다.
- 샘플 인원·날짜·파일명·초대 링크를 실제 제한·API 계약으로 확정하지 않는다.
- 기존 기능의 화면 재구성과 새 서버 기능 추가를 구분한다.
- 설계에 없는 세부 정책은 v1에서 자동 승계했다고 단정하지 않는다.

## 확정이 필요한 정책

| 항목 | 확인할 내용 | 관련 문서 |
| --- | --- | --- |
| 읽음 처리 | 자동 처리 안내와 읽음 버튼 문구 불일치 | [공지](notice.md) |
| 첨부 | 형식·크기·개수·소유권·조회 범위 | [공지](notice.md), [과제](assignment.md) |
| 제출 설정 | 허용 형식 선택 UI, 공개·참여 설정 변경 시 기존 데이터 처리 | [과제](assignment.md) |
| 양도·방출 | 활동 대상 승계, 방출 후 재가입 제한 여부 | [멤버](member.md) |
| 계정 | 회원탈퇴 데이터 처리, 기본 이름 변경 영향 | [마이페이지](account.md) |
| 알림 | 목록 읽음·이동·보관 정책, 기기 권한과 수신 설정 관계 | [알림](notification.md) |
| 화면 문구 | 스터디 정보 수정의 생성 버튼, 제출물 수정의 미제출 상태 | [설정](settings.md), [과제](assignment.md) |

> [!NOTE]
> 실제 인증·API·첨부 업로드·푸시 수신은 검증하지 않았다.
> 메모의 ‘읽음·제출 시 리더 알림’은 피드백 이후 검토 항목으로 분리했다.

# 기존 문서에서 바로잡은 내용

[← 현재 PRD](README.md) · [구현 범위](scope.md)

2026-10-08에 `263bdaf`의 웹·서버 코드를 확인하고, 기존 문서에서 실제 구현과 다르게 적힌 내용을 바로잡았다.
아래 기능은 코드에 있던 동작을 문서에 반영한 것이다. 이번 작업에서 새로 개발한 기능은 아니다.

| 항목 | 현재 코드 기준 |
| --- | --- |
| 계정 이름 수정 | 웹에서 이름을 수정할 수 있으며 최대 8자까지 허용 |
| 계정 이름의 영향 | 참여 중인 모든 스터디의 멤버 이름도 함께 변경 |
| 스터디 정보 수정 | 웹에서 스터디 이름과 설명을 수정할 수 있음 |
| 가입 제한 | 사용자별 50개, 스터디별 리더 포함 50명 |
| 초대 링크 | 토큰 발급 후 3일 만료 |
| 제출물 공개 | 웹에서 공개 여부를 선택하고 일반 멤버가 공개된 제출물을 볼 수 있음 |
| 제출 상태 | 웹·서버에 미할당·미제출·마감 후 미제출·정상 제출·지각 제출 반영 |
| 공지 확인 | 확인 대상이 본문 끝까지 읽으면 자동으로 읽음 처리 |
| 예약 리마인드 | 서버 구현, 웹 예약 입력 없음 |
| 첨부·리더 양도·스터디별 독립 이름 수정 | 현재 제공 기능에서 제외 |
| 독립 네이티브 시연 코드 | 저장소에서 제거하고 웹·서버를 PRD 범위로 사용 |

상세 정책과 코드 근거는 [현재 PRD 목차](README.md)의 각 기능 문서에서 확인한다.
[v1 문서](../v1/README.md)는 당시의 기록으로 남겨 두었다. 현재 기능을 확인할 때는 현재 PRD를 참고한다.

# 스터디 설정

[← v2 개요](README.md) · [v1 대비 변경](changes.md)

## 디자인에 있는 기능

- 스터디 정보와 관리 메뉴를 조회한다.
- 리더·스터디원은 해당 스터디에서 사용할 이름을 수정한다.
- 리더는 스터디 이름·설명을 수정한다.
- 리더는 확인 대화상자를 거쳐 스터디를 삭제한다.
- 스터디원용 설정 화면은 리더용과 별도로 제공한다.

## 현재 디자인의 정책

- 스터디 프로필 이름은 ‘해당 스터디에서 사용하는 이름’이며 8자 이하로 안내한다.
- 이름 초과 오류와 비활성 수정 버튼 상태가 있다.
- 스터디 정보 수정은 이름·설명 입력과 길이 초과 오류 화면을 제공한다. 이름 오류 안내는 최대 15자다.
- 삭제 대화상자는 복구할 수 없음을 안내한다.

## v1에서 추가·연결할 기능

- 스터디별 프로필 이름 변경 API와 화면을 추가한다.
- 기존 스터디 정보 수정 API에 입력 화면을 연결한다.
- 기존 삭제·탈퇴 기능을 v2 설정 화면 구조에 연결한다.

> [!NOTE]
> 정보 수정 화면의 버튼 문구가 ‘스터디 만들기’로 남아 있다. 실제 동작은 기존 스터디 수정이므로 문구를 확인한다.
> 이미지가 있다는 이유만으로 스터디 대표 이미지·프로필 이미지 변경 기능을 확정하지 않는다.
> 설명 제한 등 디자인에서 명확히 읽지 못한 값은 v1 정책과 대조해야 한다.

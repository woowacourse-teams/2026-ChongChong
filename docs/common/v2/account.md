# 마이페이지

[← v2 개요](README.md) · [v1 대비 변경](changes.md)

## 디자인에 있는 기능

- 계정 이름을 조회하고 수정한다.
- 푸시 알림을 켜거나 끄는 스위치를 제공한다.
- 로그아웃, 개인정보처리방침, 지원, 회원탈퇴 메뉴를 제공한다.
- 이름 길이 초과 시 오류 안내와 비활성 수정 버튼을 표시한다.

## 현재 디자인의 정책

- 이름은 8자 이하로 입력하도록 안내한다.
- 이 값은 디자인 요구다. 현재 서버 사용자 이름 모델은 최대 255자이며 이름 수정 API는 없다.
- 계정 이름은 스터디 참여 시 기본으로 설정되는 이름이다.
- 스터디별 이름은 [스터디 프로필](settings.md)에서 별도로 수정한다.
- 리더가 회원탈퇴를 시도하면 불가 안내와 리더 양도 안내를 표시한다.

## 현재 구현과 남은 작업 (2026-09-30)

- 웹 마이페이지에서 계정 이름·프로필 이미지를 조회한다. 이름 입력은 비활성 상태이며 이름 수정 API는 없다.
- 로그아웃 메뉴는 현재 브라우저의 푸시 구독을 해제한 뒤 로그아웃 API를 호출한다.
- 회원탈퇴 API와 확인 화면이 연결되어 있다. 하나라도 리더인 스터디가 있으면 서버가 탈퇴를 거부한다. 리더 양도 기능은 아직 없다.
- 탈퇴하면 사용자와 DB 외래키로 연결된 인증 세션·소셜 계정·멤버십·활동 정보·알림·Web Push 구독을 삭제하고 Refresh 쿠키를 만료시킨다.
- 푸시 스위치는 현재 브라우저 설치의 구독 등록·비활성화와 브라우저 권한을 사용한다. 계정 전체에 적용하는 별도 수신 설정은 아니다.
- 개인정보처리방침·지원 링크는 연결되어 있다.

근거: [계정 메뉴](../../../frontend/src/features/mypage/components/AccountMenuSection.tsx), [프로필 화면](../../../frontend/src/features/mypage/components/ProfileSection.tsx), [사용자 서비스](../../../backend/src/main/java/withoutc/chongchong/user/service/UserService.java).

> [!NOTE]
> 기본 이름 변경의 기존 스터디 반영 정책은 수정 기능 도입 전에 확정한다. 계정 전체 수신 설정과 네이티브 앱 권한 정책은 현재 브라우저 구독 기능과 별도다.
> 프로필 이미지는 표시되어 있지만 이미지 변경 조작은 확인되지 않아 이름 수정과 구분한다.

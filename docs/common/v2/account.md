# 마이페이지

[← v2 개요](README.md) · [v1 대비 변경](changes.md)

## 디자인에 있는 기능

- 계정 이름을 조회하고 수정한다.
- 푸시 알림을 켜거나 끄는 스위치를 제공한다.
- 로그아웃, 개인정보처리방침, 지원, 회원탈퇴 메뉴를 제공한다.
- 이름 길이 초과 시 오류 안내와 비활성 수정 버튼을 표시한다.

## 현재 디자인의 정책

- 이름은 8자 이하로 입력하도록 안내한다.
- 계정 이름은 스터디 참여 시 기본으로 설정되는 이름이다.
- 스터디별 이름은 [스터디 프로필](settings.md)에서 별도로 수정한다.
- 리더가 회원탈퇴를 시도하면 불가 안내와 리더 양도 안내를 표시한다.

## v1에서 추가·연결할 기능

- 계정 이름 조회·수정 API와 화면을 추가한다.
- 기존 로그아웃 API에 사용자 진입을 연결한다.
- 회원탈퇴와 리더 여부 검증을 추가한다.
- 푸시 수신 설정 저장과 알림 발송에 대한 반영을 연결한다.
- 개인정보처리방침·지원 링크를 연결한다.

> [!NOTE]
> 기본 이름 변경이 이미 참여한 스터디의 이름에 미치는 영향, 회원탈퇴 시 데이터 처리, 푸시 설정과 OS 권한의 관계는 미확정이다.
> 프로필 이미지는 표시되어 있지만 이미지 변경 조작은 확인되지 않아 이름 수정과 구분한다.

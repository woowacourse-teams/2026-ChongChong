# 역할과 활동 대상

[← v2 개요](README.md) · [v1 대비 변경](changes.md)

역할은 스터디별로 구분한다. v2에서는 **운영 권한, 활동 대상 여부, 제출물 공개 여부**를 함께 확인한다.

| 행동 | 리더 | 스터디원 |
| --- | --- | --- |
| 공지·과제 운영 | 작성·수정·삭제 | 열람 |
| 공지 확인 | 기존 리더 제외 기준과 대조 필요 | 할당된 경우 확인, 미할당은 열람 |
| 과제 제출 | 참여 선택 시 제출 | 할당된 경우 제출 |
| 제출물 열람 | 운영용 현황과 제출물 | 비공개는 본인, 공개는 전체 제출물 화면 제공 |
| 멤버 관리 | 리더 양도·방출 | 멤버 조회 |
| 스터디 프로필 수정 | 본인 이름 | 본인 이름 |
| 스터디 정보 수정·삭제 | 가능 | 리더용 메뉴와 구분 |
| 회원탈퇴 | 양도 안내로 차단 | 계정 메뉴 제공, 상세 처리 확인 필요 |

> [!IMPORTANT]
> 과거 글 열람 허용이 확인·제출 의무를 의미하지 않는다.
> 공개 과제의 미제출·미할당 사용자 열람 범위, 리더 양도 후 대상 승계는 상세 정책을 확정해야 한다.

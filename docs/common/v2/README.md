# 총총 PRD

[← 프로젝트 소개와 문서 목록](../../../README.md)

총총은 스터디의 공지 확인과 과제 제출 현황을 함께 관리하는 웹 서비스다.
리더는 공지와 과제를 등록하고 누가 읽었는지, 누가 제출했는지 확인한다.
스터디원은 자신이 읽어야 할 공지와 제출해야 할 과제를 확인하고 완료한다.

## 이 문서가 다루는 내용

2026-11-09 통합 개발 브랜치의 `70a09284`를 기준으로 백엔드 구현·테스트·API 계약을 대조했다.
웹 연동 여부는 해당 화면·요청·응답 검증 코드를 확인한 범위로 구분한다. 코드에 구현된 기능과 실제 배포·외부 서비스 검증 결과는 다르다.
리더가 아직 공지를 읽지 않았거나 과제를 제출하지 않은 멤버를 파악하고, 스터디원이 해야 할 일을 놓치지 않도록 돕는 기능을 정리했다.

현재 기능은 이 문서를 기준으로 확인하면 된다. [v1](../v1/README.md)은 과거 기록이며, `v2`라는 폴더 이름은 기존 문서 링크를 유지하기 위해 남겨 두었다.

## 사용자 흐름과 기능

카카오 로그인 → 스터디 생성 또는 초대 참여 → 홈에서 남은 활동 확인 → 공지 읽기·과제 제출 → 리더의 현황 확인 순서로 사용한다.

| 기능 | 현재 웹과 서버가 제공하는 동작 | 상세 |
| --- | --- | --- |
| 로그인 | 카카오 계정으로 로그인하고 여러 브라우저·기기에서 독립적인 로그인 상태를 유지한다. | [로그인](login.md) |
| 스터디 | 생성·초대 참여와 홈의 남은 활동을 제공하며, 서버에는 공개 탐색·월간 일정 조회도 있다. | [스터디](study.md) |
| 공지 | 리더가 공지를 관리하고, 스터디원이 끝까지 읽으면 읽음으로 표시한다. | [공지](notice.md) |
| 과제 | 리더가 참여·공개 범위를 정하고, 제출자는 과제를 제출하거나 수정한다. | [과제](assignment.md) |

## 구현 범위와 남은 연동

예약 리마인드는 정해진 시각에 공지 확인이나 과제 제출을 다시 안내하는 알림이다.
공지·과제 작성·수정 화면에서 예약을 입력하고, 상세 응답의 `remindAts`로 기존 예약을 불러와 유지·추가·삭제할 수 있다.
웹에는 파일 업로드·완료 확인, 공지 이미지와 과제·제출물 첨부, 다운로드 연결이 있다. [파일 업로드와 다운로드](file.md)를 참고한다.
과제 제출 대상 개별·전체 선택과 월간 캘린더는 웹에 연결되어 있다. 홈 프로필 이미지 변경·초기화와 제외된 제출물의 assigned=false 기반 수정 제한은 웹 연동이 남아 있다.
리더 양도, 스터디마다 다른 이름 사용, Google·Apple 로그인도 현재는 제공하지 않는다.

각 기능의 설명은 코드를 확인해 작성했다. 실제 서비스에 배포되었는지, 브라우저와 외부 서비스에서 정상 동작하는지는 별도 확인이 필요하다.

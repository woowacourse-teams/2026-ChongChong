# 총총 v2 PRD — Figma 기준

총총 v2는 스터디 공지·과제 관리에 **첨부, 제출물 공개, 리더 참여, 계정·스터디 설정, 알림**을 더한 디자인이다.

> [!NOTE]
> 2026-09-14에 확인한 [Figma 디자인 v2](https://www.figma.com/design/sT7K2tOQl8JtyHzuwT0nnl?node-id=1702-18637) 기준이다.
> 구현 현황은 2026-09-30 소스 `b3e3e51`로 갱신했다. 서버 구현·웹 연결·디자인 요구를 구분하며 배포 완료를 의미하지 않는다.

## 기능과 현재 현황

| 기능 | v2에서 할 수 있는 일 | v1 대비 현황·필요 작업 | 상세 정책 |
| --- | --- | --- | --- |
| 로그인 | 카카오·Google·Apple 로그인, 시작 화면·알림 권한 안내 | 카카오는 기존 기능. Google·Apple 연동과 앱 권한 흐름 추가 | [로그인](login.md) |
| 스터디·홈 | 생성·초대 참여, 내 스터디와 역할별 활동 현황 확인 | 기본 기능 유지, v2 화면과 계정·설정·알림 진입 연결 | [스터디](study.md) |
| 공지 | 공지 운영·확인 현황, 이미지·리마인드, 과거 글 열람 | 과거 글·대상 아님·자동 읽음 반영. 이미지·예약 입력 UI 남음 | [공지](notice.md) |
| 과제 | 과제 운영·제출, 파일 첨부, 리더 참여, 제출물 공개 선택 | 리더 참여 반영. 공개 범위 서버 구현·웹 미연결, 첨부 남음 | [과제](assignment.md) |
| 멤버 관리 | 멤버·초대 링크 확인, 방출·리더 양도 | 조회·방출 유지, 리더 양도 추가 | [멤버 관리](member.md) |
| 마이페이지 | 이름 수정, 푸시 설정, 로그아웃·회원탈퇴, 정책·지원 링크 | 조회·로그아웃·탈퇴·브라우저 푸시 설정 연결. 이름 수정 남음 | [마이페이지](account.md) |
| 스터디 설정 | 스터디별 이름 수정, 리더의 정보 수정·삭제 | 프로필 변경 추가, 기존 정보 수정·삭제 API 연결 | [스터디 설정](settings.md) |
| 알림 | 알림 목록, 새 글·리마인드 알림 | Web Push 발송·수신, 목록·읽음 연결. 예약 입력 UI 남음 | [알림](notification.md) |

## v1에서 추가할 핵심 기능

- **참여와 공개 정책:** 리더 과제 참여, 과제별 제출물 공개, 가입 전 글 열람.
- **첨부와 알림:** 공지·과제 이미지, 제출 파일, 예약·실제 푸시·알림함.
- **계정과 운영:** Google·Apple 로그인, 마이페이지, 스터디별 프로필, 리더 양도.

구체적인 화면·백엔드 작업은 [v1 대비 추가·변경 목록](changes.md)에서 확인한다.

> [!IMPORTANT]
> 화면에 남은 문구 불일치와 미정 정책은 [확인할 정책](scope.md)에 정리했다.
> 최초 과제 제출의 리더 알림은 구현됐다. 공지 읽음 알림은 후속 검토 항목이다.

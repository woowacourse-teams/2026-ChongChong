# 스터디

[← v2 개요](README.md) · [v1 대비 변경](changes.md)

## 디자인에 있는 기능

- 내 스터디 목록에서 스터디를 선택하거나 새로 만들고, 초대 링크로 참여한다.
- 참여한 스터디가 없을 때 빈 상태와 생성·참여 버튼을 제공한다.
- 내 스터디 화면에서 알림과 마이페이지로 접근하는 진입점을 제공한다.
- 스터디 이름과 설명을 입력해 생성하며, 길이 초과 오류 상태를 제공한다.
- 리더 홈은 공지·과제 수와 각 활동의 확인·제출 인원을 보여준다.
- 스터디원 홈은 본인의 활동을 확인하는 화면으로 구분한다.
- 스터디 내부에서 홈·공지·과제·멤버 탭과 스터디 설정으로 이동한다.

## v1에서 달라지는 점

- 생성·참여·역할별 홈이라는 기본 기능은 유지하고 v2 화면 구성으로 반영한다.
- 마이페이지·알림·스터디 설정 진입을 연결한다.
- 과거 글 열람과 리더 과제 참여에 맞게 홈·목록 집계 대상을 조정한다.

> [!NOTE]
> 디자인의 초대 링크 예시는 실제 API 주소 계약으로 사용하지 않는다.
> 인원·가입 개수와 입력 제한은 디자인에서 변경이 확인되지 않은 경우 [v1 정책](../v1/study.md)을 비교 기준으로 삼는다.

# 과제

[← v1 목차](README.md)

> [!NOTE]
> 본문은 2026-09-14 v1 스냅샷이다. 2026-10-03 현재 브랜치의 지각 제출·마감 후 미제출 상태와 최초 제출 알림 정책은 [v2 과제의 구현 반영](../v2/assignment.md#2026-10-03-백엔드-구현-반영)에서 확인한다. 프론트엔드 반영·배포 완료 여부는 별도로 확인해야 한다.

## 과제 작성·수정·삭제

- 리더가 제목, 내용, 제출 방법, 마감 시각과 리더 제출 여부를 입력한다.
- 서버 생성 요청은 제출 대상(`submissionTarget`)과 공개 범위(`submissionVisibility`)를 모두 요구한다. 현재 웹은 공개 범위를 전송하지 않아 이 브랜치의 생성 API와 계약이 맞지 않는다.
- 제출 방법에는 스터디원이 어떻게 제출하면 되는지 안내문을 작성한다.
- 리더는 과제를 수정하거나 삭제할 수 있다.

| 입력 항목 | 필수 여부 | 제한 |
| --- | --- | --- |
| 제목 | 필수 | 최대 100자 |
| 내용 | 필수 | 최대 10,000자 |
| 제출 방법 | 필수 | 최대 10,000자 |
| 마감 시각 | 필수 | 등록·변경 시 현재보다 미래 |
| 제출 대상 | 필수 | 일반 멤버만 또는 리더 포함. 웹 선택 UI 있음 |
| 공개 범위 | 서버 필수 | LEADER_ONLY 또는 ALL_STUDY_MEMBERS. 웹 입력·전송 미연결 |

## 과제 목록·상세 조회

- 리더는 스터디의 과제 목록을 조회한다.
- 스터디원도 가입 전 과제를 포함한 목록을 조회한다. 제출 상태는 대상 아님·미제출·제출 완료로 구분한다.
- 대상이 아닌 사용자는 과제를 열람할 수 있지만 제출 폼은 표시하지 않는다.
- 상세 화면에서 과제 내용, 제출 방법, 마감 시각을 확인한다.
- 목록의 다음 과제를 추가로 불러올 수 있다.

## 과제 제출·편집

- 스터디원은 과제 상세 화면의 ‘내 제출’에서 내용을 작성하고 제출한다.
- 내용과 함께 링크를 첨부할 수 있다.
- 제출한 내용과 링크를 다시 확인하고 편집할 수 있다.
- 수정은 항상 본인 제출물에만 허용된다. 서버의 공개 과제는 다른 스터디원의 제출 완료 내용도 조회할 수 있지만, 웹의 일반 멤버 공개 목록·상세 진입은 아직 연결되지 않았다.

| 입력 항목 | 웹 입력 기준 | 서버 길이 제한 |
| --- | --- | --- |
| 제출 내용 | 필수 | 최대 10,000자 |
| 링크 | 선택, URL 입력 | 최대 10,000자 |

> [!NOTE]
> 웹은 제출 내용을 필수로 요구하고 링크에 URL 입력 형식을 사용한다.
> 현재 서버는 두 항목의 길이를 검사하지만 내용 필수·URL 형식은 강제하지 않는다.

> [!IMPORTANT]
> **현재 마감 동작**
>
> 마감 시각이 지난 뒤에도 제출과 수정이 가능하다.
> 현재 제출·수정 처리에는 마감 시각에 따른 차단이 없다.

## 리더의 제출 현황·제출물 조회

- 리더는 과제를 제출한 스터디원과 아직 제출하지 않은 스터디원을 구분해 확인한다.
- 제출된 결과물 목록에서 제출자의 내용과 링크를 조회한다.
- 리더는 스터디원의 제출물을 수정할 수 없다.
- `MEMBERS_AND_LEADER`를 선택하면 리더도 제출·수정할 수 있고 현황·리마인드 대상에 포함된다. 웹의 리더 내 제출 흐름도 연결되어 있다.
- 리더 미포함으로 변경하면 리더의 기존 제출물도 삭제된다. 다시 포함하면 제출 행을 만든다.

## 제출물 공개 정책

- `LEADER_ONLY`: 목록은 리더만, 상세는 리더와 제출물 본인만 조회한다.
- `ALL_STUDY_MEMBERS`: 현재 소속 멤버는 본인의 제출 여부·대상 여부와 관계없이 다른 사람의 제출 완료 목록·상세를 조회한다. 미제출 내용은 리더와 본인만 조회한다.
- 제출·미제출 현황 API는 공개 과제에서도 리더 전용이다. 공개 설정은 타인의 수정 권한을 부여하지 않는다.
- 공개 범위 수정은 이후 조회에 반영되며 생략·null은 기존 값을 유지한다.

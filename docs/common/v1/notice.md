# 공지

[← v1 목차](README.md)

## 공지 작성·수정·삭제

- 리더가 제목과 내용을 입력해 공지를 작성한다.
- 리더는 등록한 공지의 내용을 수정하거나 공지를 삭제할 수 있다.
- 공지 내용은 텍스트로 작성한다.

| 입력 항목 | 필수 여부 | 제한 |
| --- | --- | --- |
| 제목 | 필수 | 최대 100자 |
| 내용 | 필수 | 최대 10,000자 |

## 공지 목록·상세 조회

- 리더는 스터디의 공지 목록을 조회한다.
- 스터디원은 본인에게 할당된 공지 목록과 읽음 상태를 확인한다.
- 목록에서 공지를 선택해 제목과 본문을 확인한다.
- 목록의 다음 공지를 추가로 불러올 수 있다.

## 공지 읽음 처리

- 스터디원이 공지 본문 끝까지 스크롤하면 자동으로 읽음 처리한다.
- 본문이 짧아 한 화면에 모두 보이면 바로 읽음 처리할 수 있다.
- 읽음 상태와 읽은 시각을 확인할 수 있다.

## 리더의 확인 현황 조회

- 리더는 공지를 읽은 스터디원과 아직 읽지 않은 스터디원을 구분해 확인한다.
- 리더 자신은 공지 확인 대상에 포함되지 않는다.

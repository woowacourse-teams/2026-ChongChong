# 사용자 역할

[← v1 목차](README.md)

사용자는 스터디마다 다른 역할을 가질 수 있다. 스터디를 만들면 해당 스터디의 **리더**, 초대 링크로 참여하면 **스터디원**이 된다.

| 기능 | 리더 | 스터디원 |
| --- | --- | --- |
| 스터디 홈·공지·과제·멤버 조회 | 가능 | 가능 |
| 초대 링크 조회·복사 | 가능 | 가능 |
| 공지·과제 작성·수정·삭제 | 가능 | 불가 |
| 공지 읽음 처리 | 확인 대상에서 제외 | 본인에게 할당된 공지 |
| 과제 제출·제출 내용 수정 | 제출 대상에서 제외 | 본인에게 할당된 과제 |
| 공지 확인 현황·과제 제출 현황 조회 | 전체 대상 확인 | 본인 상태 확인 |
| 제출물 내용 조회 | 스터디원의 제출물 | 본인 제출물 |
| 멤버 추방·스터디 삭제 | 가능 | 불가 |
| 스터디 탈퇴 | 불가 | 가능 |

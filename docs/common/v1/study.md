# 스터디

[← v1 목차](README.md)

## 내 스터디 목록

- 내가 만들거나 참여한 스터디를 조회한다.
- 스터디별 이름, 내 역할, 멤버 수, 미완료 공지·과제 수를 확인한다.
- 목록에서 스터디를 선택해 해당 스터디 홈으로 이동한다.
- 스터디 만들기와 초대 링크를 통한 참여 화면으로 이동할 수 있다.

## 스터디 만들기

- 스터디 이름과 설명을 입력해 스터디를 만든다.
- 만든 사용자가 리더가 되며, 생성된 스터디 화면으로 이동한다.

| 입력 항목 | 필수 여부 | 제한 |
| --- | --- | --- |
| 스터디 이름 | 필수 | 최대 15자 |
| 스터디 설명 | 선택 | 최대 30자 |

## 초대와 참여

- 리더와 스터디원 모두 멤버 화면에서 초대 링크를 확인하고 복사할 수 있다.
- 초대받은 사용자는 참여 화면에 링크를 붙여넣어 스터디에 참여한다.
- 초대 링크로 참여 화면에 접근하면 링크가 입력란에 자동으로 채워진다. 참여 버튼을 누르면 가입한다.
- 참여한 사용자는 스터디원이 되고 해당 스터디 홈으로 이동한다.
- 이미 참여한 스터디에 중복으로 가입할 수 없다.

> [!IMPORTANT]
> **참여 인원과 스터디 수**
>
> 스터디당 리더를 포함해 최대 30명이 참여할 수 있다.
> 한 사용자는 직접 만든 스터디를 포함해 최대 50개 스터디에 소속될 수 있다.

## 스터디 홈

- 하단의 홈·공지·과제·멤버 탭으로 이동한다.
- 리더는 아직 모든 대상자가 확인하지 않은 공지와 제출을 마치지 않은 과제의 현황을 확인한다.
- 스터디원은 본인이 아직 읽지 않은 공지와 제출하지 않은 과제를 확인한다.
- 홈에 표시된 활동을 선택해 상세 내용을 확인한다.

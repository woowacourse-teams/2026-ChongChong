# 총총 v1 PRD

총총은 **스터디의 공지 확인과 과제 제출 현황을 함께 관리하는 서비스**다.
리더는 공지·과제를 등록하고 진행 현황을 확인하며, 스터디원은 공지를 읽고 과제를 제출한다.

> [!NOTE]
> 2026-09-14에 확인한 `backend/`·`frontend/`의 현재 구현 기준이다.
> 기준 커밋: `b9b34c363f2e030adcfbae5f4e10ffd56b8580c7` (`origin/dev`).

## 현재 제공하는 기능

현재 웹은 **로그인 → 스터디 생성·참여 → 공지 확인·과제 제출 → 리더의 진행 현황 확인** 흐름을 제공한다.
아래 기능은 화면과 백엔드 API가 연결되어 있다.

| 기능 | 사용자가 할 수 있는 일 | 상세 정책 |
| --- | --- | --- |
| 로그인 | 카카오 계정으로 로그인하고 인증 상태를 유지한다. | [로그인](login.md) |
| 스터디 생성·참여 | 스터디를 만들거나 초대 링크로 참여하고, 내 스터디 목록에서 선택한다. | [스터디](study.md) |
| 스터디 홈 | 리더는 전체 진행 현황을, 스터디원은 본인의 미확인 공지·미제출 과제를 확인한다. | [스터디](study.md) |
| 공지 | 리더는 공지를 작성·수정·삭제하고 읽음 현황을 확인한다. 스터디원은 본문을 읽고 확인 상태를 남긴다. | [공지](notice.md) |
| 과제 | 리더는 과제를 등록·수정·삭제하고 제출 현황과 결과물을 확인한다. 스터디원은 내용·링크를 제출하고 편집한다. | [과제](assignment.md) |
| 멤버 관리 | 멤버 목록과 초대 링크를 확인한다. 리더는 추방·스터디 삭제를, 스터디원은 탈퇴를 할 수 있다. | [멤버 관리](member.md) |

## 아직 웹에서 제공하지 않는 기능

| 기능 | 현재 현황 |
| --- | --- |
| 스터디 정보 수정 | 수정 API는 있으나 웹 수정 화면은 없다. |
| 로그아웃 | API와 호출 함수는 있으나 웹에서 실행하는 화면은 없다. |
| 리마인드 예약 | 서버에 예약 시각을 저장할 수 있으나 웹 예약 입력은 없다. |
| 푸시 알림 | 토큰·발송 기록 저장 기반이 있으며 실제 푸시 발송은 연결되지 않았다. |

> [!NOTE]
> 역할별 권한은 [사용자 역할](roles.md), 활동 대상과 구현 범위는 [현재 기능의 범위](scope.md)에서 확인한다.
> 입력 제한·마감 처리 등 세부 정책은 각 기능 문서에 정리했다.

> [!NOTE]
> 소스와 화면의 API 연결을 기준으로 정리했다. 이번 문서 작업에서는 실제 로그인·HTTP 통합 테스트·푸시 수신을 실행하지 않았다.
